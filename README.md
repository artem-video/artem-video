## MarkFlow — черновик выпуска в Premiere Pro

Рутину — машине, монтаж — вам. MarkFlow собирает черновик выпуска в Premiere Pro по сценарию:
убирает неудачные дубли, ставит лайвы, кладёт звук. Это скрипты, а не нейросеть, поэтому часовая запись
обрабатывается за секунды.

- **[markflow-draft](https://github.com/artem-video/markflow-draft)** — бесплатный скилл для Claude,
  ChatGPT, Gemini и других нейросетей: черновик говорящей головы по SRT и сценарию.
- Полная версия для студий и монтажёров: **[artemsytnik.com/markflow](https://artemsytnik.com/markflow/)**
